# 知识点与能力地图

本节整理自 `bytedance-ecom-security-2026` case 的知识体系，并按后端平台实践重排。

## 学习顺序

1. 通用基础：`Go / Java / Linux / DB / 缓存 / MQ / 服务化`
2. 岗位核心：`架构设计 / 稳定性 / 安全性 / 数据服务 / 业务抽象`
3. 业务映射：`电商安全 / 风险运营 / 内容质量协同 / AI 增强边界`

## 核心知识块

### 1) 电商安全与风险运营

- 商家风险事件建模与证据链组织
- 风险规则、专项治理、策略灰度发布
- 召回率、误伤率、处置效率之间的权衡

### 2) 业务抽象与架构设计

- 复杂业务流程抽象：事件 -> 判定 -> 案件 -> 处置
- 状态机设计与可追踪生命周期
- 可扩展接口边界与模块拆分策略

### 3) 后端服务工程能力

- API 设计、分层治理与契约稳定性
- 超时、重试、幂等、补偿机制
- 服务发布与回滚策略

### 4) 数据基础设施与中间件

- MySQL 索引、事务与性能优化
- Redis 缓存策略与一致性治理
- RabbitMQ 削峰、重试、死信、回放

### 5) 服务可靠性与安全性

- 限流、熔断、降级、容量评估
- 审计日志、鉴权与安全基线
- 压测、慢查询分析与性能瓶颈定位

### 6) 大模型应用工程化（增强层）

- LLM sidecar 服务封装与调用治理
- 结构化输出与失败回退机制
- 作为增强模块接入，不替代规则主链路

## 面试高频表达

- 如何支撑运营专项治理并形成闭环
- 如何同时优化风险召回与误伤控制
- 如何把复杂业务抽象成稳定模块
- AI 功能失败时如何保证主流程可用
