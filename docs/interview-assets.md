# 面试与简历素材（仓库版）

## 简历 Bullet（可直接改写使用）

- 设计并实现电商安全与商家风险运营后端平台，完成风险事件接入、规则评估、案件状态机和运营数据接口。
- 基于 MySQL、Redis 和 RabbitMQ 搭建异步处置与审计链路，通过幂等、重试和回放机制保证线上稳定性。
- 引入 AI Copilot 辅助风险摘要、相似案件检索和排查建议，作为平台增强模块而非主判定链路。

## 项目讲解顺序（建议）

1. 业务问题
- 电商安全后端不仅要判定风险，还要支撑商家侧运营处置和专项治理。

2. 系统设计
- `risk ingestion -> rule engine -> case workflow -> operations data APIs -> copilot`

3. 工程细节
- 状态机、审计日志、MQ 重试、缓存一致性如何支撑线上服务。

4. 结果表达
- 处置效率、误伤控制、平台扩展能力如何被量化。

## 高频追问清单

- 电商安全系统如何支撑运营专项治理？
- 风险发现与误伤控制如何同时优化？
- 如何把复杂业务拆成稳定模块？
- 架构设计里如何权衡扩展性与交付速度？
- 如何做服务拆分并保持模块可复用？
- 线上服务如何控制稳定性风险？
- AI 功能失败时系统如何保证可用性？

## 自我介绍主线

- 我做的是风险运营后端平台，不是单点算法实验项目。
- 我重点讲业务抽象、服务拆分、中间件治理和 AI 增强边界设计。
